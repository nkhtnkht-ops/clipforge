Clipboard refined

見た目の派手さより、毎日使う道具としての密度を優先。白黒の余白と実画面で、プロダクトの働きが伝わる構成。

01
Core workflow

一枚のパネルに、
よく使う操作を集約。

履歴を探す、定型文を貼る、スクショを扱う。小さな操作をひとつの流れに揃えることで、 Windows の作業テンポを崩しません。

検索できる履歴

コピーしたテキストや画像を、記憶に頼らず一覧から戻せます。

定型文を即貼り付け

よく使う文面を整理し、タブ切り替えと検索からすぐに呼び出せます。

スクショも同じ導線へ

範囲キャプチャと注釈編集を、クリップボード作業の延長に置きます。

02
Core features

量産型の横並びカードではなく、操作の目的がすぐ読める4項目に整理。画像に頼りすぎず、 実用アプリらしい情報密度で見せます。

03
Screenshot tools

スクショを撮った後の、
ひと手間まで。

画像を撮って、少し説明を足して、必要な形式で渡す。スクショ周辺の作業を ClipForge の中で完結しやすくします。

注釈エディタ

キャプチャ画像に矢印・囲み・テキスト・手書きを加え、説明しやすい状態で保存・共有できます。編集中はウィンドウが自動でフルスクリーンに拡張。

右クリック印刷 / JPEG

スクショ履歴から印刷、JPEG 保存、コピーを選択。画像を扱う後工程を短くします。メール本文への直接貼り付けにも対応。

05
How it works

コピー、呼び出し、貼る。 それだけでいい。

LP の説明は増やしすぎず、アプリの使い方が自然に想像できる 3 ステップに絞ります。

01

コピーする

テキスト、画像、スクショをいつもの操作で履歴へ。

02

呼び出す

パネルから履歴や定型文をすばやく選びます。

03

貼る

必要な場所へ戻して、作業をそのまま続けます。
